## 建议的学习路径（结合本地代码）

1. **先读本地 `01-项目总览.md`** —— 10 分钟建立全貌：三条业务流程主线（文生图创作 / 编辑器修图 / Agent 对话修图）。
2. **对照 `02-项目大纲.md` 逐期读代码** —— 每期大纲都列了具体知识点，直接能映射到源码文件（映射表见 `../README.md`）。
3. **重点啃第 5、9 期（Agent 对话框架 / 多步计划）** —— 这是本项目区别于 CRUD 项目的核心，也是审计发现 P0 问题（步骤重复执行）的所在，学习时带着 `OPTIMIZATION-ROADMAP.md` 里 A1 的视角看，理解会更深。
4. **官方 7 个扩展点是简历区分度所在** —— 本仓库已完成第 1 个（智能改尺寸/营销图/批量/ZIP），其中 4 个的技术底座与优化路线 Track A/B 重叠，修完问题顺手完成扩展点。
